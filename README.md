<h1 align="center">orrery</h1>
<p align="center"><i>the mechanics of your day</i></p>

Планировщик и трекер учебного времени, который сделал студент для студентов.
Засекайте время одним касанием, планируйте день и смотрите свою неделю в виде модели солнечной системы.

## Установить

- **Android:** скачайте APK со страницы [последней версии](../../releases/latest), откройте файл и разрешите установку из этого источника. Если появится предупреждение Play Защиты, нажмите «Подробнее» → «Всё равно установить».
- **iPhone, планшет, компьютер:** откройте [сайт](https://github.com/orrery-family/planner) приложения в браузере. На iPhone — в Safari: «Поделиться» → «На экран „Домой“».

## Что умеет

- таймер одним касанием и счётчик в шторке уведомлений;
- помодоро с настраиваемыми кругами;
- задачи, план дня, дедлайны и проекты;
- журнал: записи можно исправлять и делить на две;
- итоги недели и месяца, цели по занятиям;
- виджет на рабочий стол;
- 9 тем, своя тема с фото, шрифт для дислексии;
- 10 языков;
- работает без интернета, все данные хранятся только на вашем устройстве.
