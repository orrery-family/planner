# ORRERY в интернете через GitHub Pages

GitHub Pages — бесплатный хостинг от GitHub. Ты загружаешь туда файлы приложения и получаешь постоянную ссылку вида
`https://твой-логин.github.io/orrery/`.

По этой ссылке ORRERY открывается:
- **на iPhone** — как приложение с иконкой на экране «Домой»;
- **на Android** — так же, если не хочется ставить APK;
- **на компьютере** — в браузере или отдельным окном.

Приложение работает **без интернета**: после первого открытия оно сохраняется на устройстве.

Программировать ничего не нужно, всё делается мышкой на сайте github.com. Займёт минут 15.

---

## Что в архиве

| Файл | Что это |
|---|---|
| `index.html` | Само приложение ORRERY (шрифты встроены) |
| `manifest.webmanifest` | «Паспорт» приложения: название, иконки, цвета. Благодаря ему ORRERY ставится на экран как приложение |
| `sw.js` | Помощник для работы без интернета |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | Иконки для Android и компьютера |
| `apple-touch-icon.png` | Иконка для iPhone |
| `README.md` | Эта инструкция (загружать на GitHub не обязательно) |

## Шаг 1. Заведи аккаунт на GitHub

1. Открой https://github.com и нажми **Sign up**.
2. Введи почту, придумай пароль и **логин (username)**.

   ⚠️ **Логин будет виден в ссылке на приложение** (`логин.github.io`). Подумай, под каким именем ты хочешь, чтобы его видели. Можно взять нейтральный логин, не связанный с настоящим именем, например `orrery-app`.
3. Подтверди почту кодом из письма.

Бесплатного тарифа хватает.

## Шаг 2. Создай репозиторий

Репозиторий — это просто папка на GitHub.

1. Справа вверху нажми **+** → **New repository**.
2. **Repository name:** `orrery` (маленькими латинскими буквами — это слово будет в ссылке).
3. Выбери **Public**. На бесплатном тарифе GitHub Pages работает только с публичными репозиториями.
   Публичным будет только **код приложения**. Твои задачи и засечённое время хранятся на твоём устройстве и на GitHub не попадают.
4. Остальное не трогай и нажми **Create repository**.

## Шаг 3. Загрузи файлы

1. Распакуй архив `orrery-web.zip` на компьютере.
2. На странице нового репозитория найди ссылку **uploading an existing file** и нажми её.
   (Если её не видно: **Add file → Upload files**.)
3. Открой распакованную папку, выдели **все файлы внутри** (Ctrl+A) и перетащи их в окно браузера.
   Перетаскивать нужно **сами файлы, а не папку**: `index.html` должен лежать в корне репозитория, а не в подпапке.
4. Внизу нажми зелёную кнопку **Commit changes**.

Должно получиться 7 файлов (и README, если загрузила его тоже).

## Шаг 4. Включи GitHub Pages

1. В репозитории открой вкладку **Settings** (шестерёнка вверху).
2. Слева в меню выбери **Pages**.
3. В разделе **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`, папка `/ (root)`
   - нажми **Save**.
4. Подожди 1–3 минуты и обнови страницу. Вверху появится надпись **Your site is live at** и ссылка:
   `https://твой-логин.github.io/orrery/`

Открой ссылку и проверь, что приложение загрузилось. Её можно отправить друзьям — у каждого будет свой отдельный дневник.

## Шаг 5. Установи на iPhone

1. Открой ссылку **именно в Safari**. Во встроенном браузере Telegram или Instagram такой кнопки не будет. Если открыла там — нажми «Открыть в Safari».
2. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх) внизу экрана.
3. Пролистай вниз и выбери **«На экран „Домой“»**.
4. Название оставь `ORRERY` и нажми **«Добавить»**.

На экране появится иконка со звездой. ORRERY будет открываться на весь экран, без адресной строки, как обычное приложение.

## Шаг 6. Установи на Android (если без APK)

1. Открой ссылку в **Chrome**.
2. Меню **⋮** → **«Добавить на главный экран»** или **«Установить приложение»**.

## Шаг 7. На компьютере

1. Открой ссылку в **Chrome** или **Edge**.
2. В адресной строке справа появится значок установки (монитор со стрелкой) → **Установить**. ORRERY откроется в отдельном окне, и его можно закрепить на панели задач.
3. Горячие клавиши: **1–9** — запустить/остановить занятие, **пробел** — стоп, **N** — новая задача.
4. **Кнопки-закладки:** открой занятие (вкладка «Занятия» → нажми на занятие) → **«Сделать закладку»** → нажми **Ctrl+D** (⌘D на Mac) и сохрани на панель закладок. Нажатие на такую закладку сразу запускает отсчёт этого занятия.

## Как обновлять приложение

Когда я пришлю новую версию:

1. Открой репозиторий → **Add file → Upload files**.
2. Перетащи новый `index.html` (GitHub сам заменит старый).
3. Нажми **Commit changes**.
4. Через пару минут открой приложение **с интернетом**. Если видна старая версия — закрой приложение полностью и открой ещё раз.

Твои данные при обновлении не пропадают.

---

## Где хранятся данные

- Всё хранится **на устройстве, в этом приложении**. На GitHub и в интернет ничего не уходит.
- iPhone, APK на Android, версия в claude.ai и браузер на компьютере — **это разные дневники**. Сами они не синхронизируются.
- Перенести данные можно вручную: **Настройки → «Скачать копию»** на одном устройстве и **«Загрузить копию»** на другом.
- ⚠️ **На iPhone:** если удалить иконку с экрана, данные удалятся вместе с ней. Иногда делай «Скачать копию».

## Чем версия для iPhone отличается от APK

| | APK (Android) | GitHub Pages (iPhone и все остальные) |
|---|---|---|
| Работа без интернета | да | да |
| Иконка на экране | да | да |
| Таймер в шторке уведомлений | да | нет |
| Виджет, ярлыки на иконке | да | нет |
| Напоминания о задачах | да | нет |

Таймер при этом всегда считает правильно: время засекается от момента старта, даже если приложение закрыто.

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| Ссылка показывает **404** | Подожди ещё пару минут. Проверь, что `index.html` лежит в корне репозитория, а не в папке `orrery-web`. Если в папке — удали её и загрузи файлы заново (шаг 3). |
| Нет пункта **«На экран „Домой“»** | Ссылка открыта не в Safari. Скопируй её и вставь в Safari. |
| После обновления видна старая версия | Закрой приложение полностью (смахни из списка открытых) и открой снова с интернетом. |
| Иконка без звезды, просто буква | Удали иконку и добавь заново — iPhone запоминает иконку в момент добавления. |
